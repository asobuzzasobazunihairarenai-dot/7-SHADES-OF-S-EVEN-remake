# ランク戦（フリーマッチ）仕様 v1

ユーザー（YGM）と 2026-08-16 に合意した、フリーマッチ＝ランク戦の仕様。実装の「正」とする。
既存の「対戦数ティア（ランクリング。stats-profile.js の getTierInfo、対戦数に応じた色付きリング）」
とは **別物として並立** する、新しい競技ランク。

## 対戦形式（v1）

- **2人戦（1対1）から先行**。3〜4人ランクは将来（ポイント表に 3-4 人分も用意してあるが v1 では未実装）。
- **マイデッキ戦**（各自のデッキ。既存の openDeckSelect を流用）。
- **自動処理モード必須・ターンタイマー必須**（両者に強制ON）。不正・放置対策の要。
- **無色（白黒）カードは含めない**（説明書の推奨・既定に合わせる）。

## ランク構成

下から順に 7 段階：

1. ブロンズ
2. シルバー
3. ゴールド
4. プラチナ
5. ダイヤモンド
6. マスター
7. レジェンド

各ランクには、以下の順で点灯する **七色ゲージ** がある（このゲームの 7 色ロックと世界観を揃える）：

赤 → 橙 → 黄 → 緑 → 青 → 桃 → 紫

**7 ポイント獲得して全色が点灯すると、次のランクへ昇格**。

### ゲージの基本処理

- 獲得ポイントに応じて色が（前＝赤側から）点灯
- マイナスポイントを受けると、後ろの色（紫側）から消灯
- 7 ポイントを超えた分は次ランクへ持ち越し
- 現在ランクの 0 ポイント未満にはならない
- シーズン中は一度昇格したランクから降格しない（＝シーズン中はランクが下がらない。ゲージだけが上下する）

例：ゴールド 5 ポイントで 4 人戦 1 位になり「+4」を獲得 → 5+4=9 → ゴールドの 7 を満たしてプラチナへ昇格、
余った 2 ポイントがプラチナのゲージに入る。

## ポイント

ブースト／通常の判定は「**対戦開始時の現在ランク**」で行う。

### ブロンズ〜ゴールド（ランクブースト）

序盤を進みやすくするため、プラス側だけを大きくする（**負けのマイナスは増やさない**）。

| 対戦人数 | 1位 | 2位 | 3位 | 4位 |
|---|---|---|---|---|
| 2人戦 | +3 | −1 | — | — |
| 3人戦 | +3 | 0 | −1 | — |
| 4人戦 | +4 | +2 | −1 | −2 |

昇格までの目安：2人戦1位 約3勝／3人戦1位 約3勝／4人戦1位 約2勝／4人戦2位 約4回。

### プラチナ以降（通常）

| 対戦人数 | 1位 | 2位 | 3位 | 4位 |
|---|---|---|---|---|
| 2人戦 | +1 | −1 | — | — |
| 3人戦 | +1 | 0 | −1 | — |
| 4人戦 | +2 | +1 | −1 | −2 |

4人戦は勝利難度が高いため、1位 +2・4位 −2・2位にも +1。

**※ v1 は 2 人戦のみ実装。3-4 人分の行は将来用に温存。**

## レジェンド到達後

- レジェンドは最上位なので、以降は昇格の代わりに **レジェンドポイント（LP）** を積み上げる。
- **レジェンド内ランキング（1位〜）** で競う（多くのゲームの最上位と同じ）。
- 降格なし。

## シーズン制

- **1 か月単位**（毎月 1 日に新シーズン開始、月末にシーズン終了）。
  - ※開始のタイムゾーン・時刻は要確認（JST 00:00 等を想定。実装時に確定する）。
- シーズン中のランク降格なし。
- **新シーズンは前シーズンの到達ランクの 2 つ下から開始**、ゲージは 0 ポイント。
- 新規プレイヤー（初参加）は **ブロンズ・0 ポイント** から開始（※明記が無かったため既定として置く。要確認）。

翌月の開始ランク対応表：

| 前シーズンの到達ランク | 翌月の開始ランク |
|---|---|
| レジェンド | ダイヤモンド |
| マスター | プラチナ |
| ダイヤモンド | ゴールド |
| プラチナ | シルバー |
| ゴールド | ブロンズ |
| シルバー | ブロンズ |
| ブロンズ | ブロンズ |

※シーズン中は降格しないため、シーズン終了時の「現在ランク」＝「到達ランク（ピーク）」になる。

## マッチメイキング（v1・低母数対策込み）

専用サーバーは無い（静的サイト＋Supabase）ため **待機キュー方式**。Supabase に待機キューのテーブル＋
原子的にペアを組む RPC（既存の部屋システムの SECURITY DEFINER ＋行ロック＋「次に見た人が処理」
パターンを応用）。

### 基本フロー（レディチェック方式）

低母数で一番起きやすい事故＝「マッチしたのに片方が席を外していて、開始早々に切断扱いで敗北」を
防ぐため、**マッチ成立＝即開始にしない**。2 つの時間を分ける：

- **キュー待ち（長くて OK）**：「対戦相手を探しています」で待つ時間（数分〜30 分想定）。タブは開いた
  まま。ハートビートでキュー登録を維持（＝ハートビートが途切れる＝離脱で自動的にキューから外れる）。
- **レディチェック（短い・60〜90秒目安）**：システムが「両者ともハートビートが生きている 2 人」を
  ペアにすると、両者の待機画面が「相手が見つかりました！ N 秒以内に『対戦開始』を押してください」に
  切り替わる。

**レートもタイマーも、両者が『対戦開始』を押して初めて起動する。**

- 両者が時間内に押す → 正式開始（部屋作成・レート/タイマー起動）。
- 片方が押さない → 押さなかった側はキューから外す（AFK 扱い・**ペナルティなし・レート変動なし**）、
  押した側はキュー先頭に戻して次の人を待つ。
- 正式開始後の切断・放置は「切断＝一定時間放置で相手勝ち（猶予あり）」を適用（＝本人が居ると確認した
  上でのバックレなので妥当）。

許容ランク差：**当面は誰でも（先着）**。母数が増えたら近いランク優先などに絞る。相手待ち中はキャンセル可能。

### 低母数対策（v1 採用）

- **合言葉でフレンドとランク戦（約束制）**：部屋コードで知り合いと私的なランク戦（Discord 等で時間を
  合わせる）。既存の部屋システムを流用でき、初期の少人数で最も確実に対戦できる。**正式なランク戦として
  レート反映**する。※知り合い同士が結託して勝敗を作る farming は初期は許容し、将来対策を検討（同一
  ペアの連続対戦の検知・レート上限・非公開戦は反映しない、等）。
- **待機中に CPU 練習**：探している間 CPU 戦で遊べる。人間が見つかったら中断して呼び戻す。CPU 戦は
  **ランク無効**（farming 防止）。
- **待機人数の表示**：「現在 N 人が対戦相手を探しています」。0 人でも正直に見せて期待値を整える。
- **通知の強化**：マッチ成立時に音＋タブのタイトル/ファビコン点滅（任意でブラウザ通知）。別タブで作業
  中でも気づける。※タブを閉じても届く本物のプッシュ通知（PWA / Web Push）は将来枠。

## 勝敗・放棄

- 7 色ロックで勝ち（既存ルール）。
- タイマー切れは自動処理で進むので **試合自体は止まらない**。
- **切断・一定時間放置 → 相手の勝ち**（切断には少し猶予を持たせる）。

## ランク称号演出

- 各ランクに専用の称号画像を用意（背景透過のアニメーション WebP）。
- 上位ランクほど発光やオーラが豪華になる。
- レジェンドでは七色が完全に現れる。
- 昇格時：七色ゲージ完成 → 称号変化へつなげる演出。

### 素材（用意済み・2026-08-16）

`画像素材/ランクバッジ/`（gitignore 対象＝ローカルのみ）に 7 ランク分揃っている：

- **アニメ版**：`画像素材/ランクバッジ/アニメ/{bronze,silver,gold,platinum,diamond,master,legend}-rank-animated.webp`
  （背景透過のアニメーション WebP、既に英語ファイル名）
- **静止版**：`画像素材/ランクバッジ/静止/{ブロンズ,シルバー,ゴールド,プラチナ,ダイヤモンド,マスター,レジェンド}.webp`

実装時、他の実物素材と同じ運用で `assets/rank-badges/` へ英名でコピーして使う
（`画像素材/` は gitignore、`assets/` は公開リポジトリ（GitHub Pages）に含める）。
アニメは重い（レジェンドで約 1.9MB）ので、一覧では静止版・獲得/昇格演出でアニメ版、のような使い分けも検討。

## 実装フェーズ（想定）

1. **データ土台（Supabase）**：ランク・ゲージ・シーズン・LP を持つテーブル＋ポイント計算/昇格ロジックの
   RPC（クライアントを信頼しすぎないよう SECURITY DEFINER 側で確定）。
2. **マッチメイキング**：待機キューテーブル＋原子的ペアリング RPC → 自動で部屋作成・対戦開始
   （自動処理＋タイマーを強制ON）。
3. **結果反映**：対戦終了（勝敗）→ ポイント計算 → ランク/ゲージ更新 → 結果画面（七色ゲージ演出・昇格演出）。
4. **UI**：ホームの「フリーマッチ（ランク戦）」タイル → マッチング画面 → 対戦 → 結果。ランク表示
   （七色ゲージ・段位）。
5. **シーズン処理**：月次ロールオーバー（新シーズンで 2 ランク下・ゲージ 0）。
6. **称号アート反映**（素材はユーザー用意）。
