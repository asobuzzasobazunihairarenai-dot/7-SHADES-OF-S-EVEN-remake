「OS」になるには、共通語彙が先に要る

ルールを増やすことではなく、意味を固定することが、無数の遊びを支える。

トランプで数百の遊びが成立するのは、ルールが多いからではありません。 どの遊びでも意味が変わらない約束があるからです。 「エースは強い」「ジョーカーは万能」「スートは4つ」。 これを一度覚えれば、次のゲームは半分覚えた状態から始められます。

エイブンで同じことを起こすには、色と数の意味を全ルールで固定する必要があります。 バラバラだと、8本が「8個の無関係なゲーム」になり、OSになりません。 以下の語彙は8本すべてで一度も破綻していません。

色と数の意味

コンポーネントには文字が一切ない。ルールは「色」「数」「位置」「表裏」だけで書ける必要がある。

虹の環

7色は輪になっている。「環で隣の色」と言えば、この輪で隣り合う2色のこと。 赤の隣は橙と紫。この輪は全ルールで同じで、ゲームごとに変わることはない。

カードの見え方（CUDアイコン案つき）

色覚に依存しないよう、色ごとに固有の形を持たせる。 形だけで10色を見分けられることが条件。金型を切る前に、デジタルで先に確定できる部分。

8タイトル

すべて「セットアップ・手番・勝利条件」の3点で書いてある。口で2分で教えられることを基準に削ってある。

第 1 のゲーム

スペクトル・ラッシュ

速度2〜4人10分手番なし・全員同時

参考にした遊び — スピード、ウノ、ナーツ

使うもの
カード 7色 × 0〜9（70枚）＋ 虹 0〜3（4枚）＝ 74枚
ヘクス 7色 各1枚
ジェム 白 1個（特権マーカー）／ 虹 10個（勝ち星）
砂時計 1個
セットアップ
  1. 7色のヘクスを、虹の環の順に輪のように並べる。
  2. 白ジェムを赤のヘクスに置く（＝いまの特権色は赤）。
  3. カードをシャッフルし、中央に2枚を表向き（＝2つの場）。
  4. 残りを人数で均等に配る（＝各自の山、裏向き）。余りは脇へ。
  5. 各自、山から4枚を手札に。砂時計をひっくり返して開始。
進行 — 手番はない。早い者勝ち

手札から、2つの場のどちらかに重ねる。条件はどちらか片方を満たせばよい。

色つながり … 同じ色 か、環で隣の色

数つながり … 同じ数 か、1違いの数

  • 特権色のカードは、条件を無視してどこにでも置ける。
  • 虹はどの色としても扱える。
  • 置いたら山から1枚補充して、常に手札4枚。
  • 7を置いた人は、白ジェムを好きな色のヘクスへ動かす（特権色が変わる）。
  • 全員が置けなくなったら、一斉に山から1枚ずつめくって場に足す。
勝利条件

山と手札を先に0にした人の勝ち。砂時計が落ちたら、残り枚数が最少の人の勝ち。 勝った人は虹ジェムを1個取り、3個先取でゲーム勝利。

第 2 のゲーム

ルミナス・トリック

トリックテイキング3〜5人25分

参考にした遊び — ウィザード、ナポレオン、ハーツ

使うもの
カード 人数と同じ数の色 × 0〜9 ＋ 白と黒（各 0〜人数-1）
3人＝36枚 ／ 4人＝48枚 ／ 5人＝60枚（つねに各自12枚）
ダイス 各自1個（担当色）
ジェム 虹（得点）
セットアップ
  1. 各自、使う色から1色を選ぶ（＝担当色）。その色のダイスを手元に置く。
  2. カードをシャッフルして全員に12枚ずつ配る。
進行 — 3ラウンド

① 宣言 … このラウンドで取るトリック数を予想し、自分のダイスをその目にして伏せる。0のときはダイスを裏返して置く。全員そろったら一斉に公開。

② トリック … スタートプレイヤーから1枚ずつ出す。

  • リードされた色を持っていれば、その色を出さなければならない。
  • 白と黒は色を持たないので、いつでも出せる。ただし勝てない。

基本は、リード色のカードで数字が一番大きい人が勝つ。

黒が出たら「一番小さい人が勝つ」に切り替わる。白が出たら「一番大きい人が勝つ」に戻る。何枚出ても、最後に出た白か黒が決める。

③ 決算 … 宣言がぴったり当たっていたら（宣言数＋3）個のジェム。外したら0個。さらに自分の担当色のカードで勝ったトリック1つにつき＋1個。

勝利条件

3ラウンド後、ジェムが一番多い人の勝ち。

ダイスの使い方がこのゲームの発明。数字を書かずに「いくつ取るか」を宣言できる。10色×各1個という構成は、これができるためにある。

第 3 のゲーム

プリズム・リンク

パズルレース2〜4人20分

参考にした遊び — ラビリンス、つなぎパズル系

使うもの
カード 7色 × 0〜9（70枚）＋ 虹 0〜3（4枚）
ヘクス 白 1枚（スタート）＋ 各自の担当色 1枚（ゴール）
ミープル 各自3体（担当色）
セットアップ
  1. カードをシャッフルし、5×5＝25枚を表向きに並べる（＝道）。
  2. 中央のマスに白ヘクスを重ねて置く（＝スタート）。
  3. グリッドの各辺の外側に、各自の担当色ヘクスを1枚ずつ置く（＝自分のゴール）。
  4. 各自のミープル3体を中央の白ヘクスに乗せる。
  5. 残りを山にし、各自3枚の手札。
手番 — 時計回り

① 道を作り替える … 手札1枚を、グリッドの好きなマスに重ねて置く。一番上だけが有効。

② 動かす … ミープルを1体、隣（上下左右）のマスへ移動。条件は同じ色か環で隣の色か数字が1違い。

移動した先から、条件を満たす限り何回でも続けて動ける（＝連鎖）。

③ 補充 … 手札を3枚に戻す。

  • 中央の白ヘクスからは、どのマスへでも1歩目を出せる。
  • ゴール … グリッドの端にいて、そのマスのカードが自分の担当色か環で隣の色なら、ゴールヘクスへ移せる。
  • 虹はどの色としても扱える。
勝利条件

自分のミープル3体を先にゴールさせた人の勝ち。

デジタル化はここから始めるのがおすすめ。盤がグリッドで固定なので自由配置の実装を後回しにでき、カード・ヘクス・ミープルの3種類を一度に検証できる。連鎖の気持ちよさはデジタルと特に相性がいい。

第 4 のゲーム

カラー・マーケット

心理戦・投資3〜5人30分

参考にした遊び — ミリオンダラー、電力会社の市場、株式系

使うもの
カード 7色 × 0〜15（112枚）＋ 白5枚 ＋ 黒5枚
ヘクス 7色 各1枚（＝7つの銘柄）
ジェム 各自 担当色10個（投資）／ 虹（現金・得点）
ダイス・袋 7色のダイス ／ 巾着袋
セットアップ
  1. 7色のヘクスを一列に並べる（＝銘柄）。
  2. 各ヘクスの上にカードを1枚ずつ表向きに置く（＝初期株価）。
  3. 各自、担当色のジェム10個を持つ。
  4. カードをシャッフルし、各自8枚配る。

株価＝その銘柄の一番上のカードの数字。

手番 — 8ラウンド・時計回り

① 株価を動かす … 手札1枚を好きな銘柄に積む。株価がその数字になる。

  • 白 … 株価は15（高騰）
  • 黒 … 株価は0（暴落）
  • 0 … 株価0（無に戻る）

② 投資 か 売却（どちらか1回）

  • 投資 … ジェムを1個、好きな銘柄の脇に置く。
  • 売却 … ジェムを1個回収し、そのときの株価と同じ数の虹ジェム（現金）を受け取る。
決算 — 8ラウンド後
  1. 巾着袋に7色のダイスを入れ、1個引く。その色が本命銘柄。
  2. 各銘柄に残っている自分のジェム × 最終株価 ＝ 得点（本命銘柄は2倍）。
  3. 手元の虹ジェム（売却益）は1個1点。
勝利条件

得点が一番多い人。

狙いどころ。どこに投資したかは全員に見えている。だから「上げたい色」がバレると黒を落とされる。早く売って現金にするか、最後まで持って本命を狙うか。

第 5 のゲーム

プリズム・タワー

協力パズル1〜4人15分ソロ可

参考にした遊び — 花火（ハナビ）、ザ・ゲーム、Magic Maze

使うもの
カード 7色 × 0〜9（70枚）
ジェム 白3個（ひび）／ 各自 担当色1個（補強）
ミープル 虹4体（支柱）
砂時計 1個
セットアップ
  1. カードをシャッフルし、1枚を表向きに置く（＝塔の1段目）。
  2. 各自4枚の手札。自分の手札は自分だけが見る。
  3. 白ジェム3個と虹ミープル4体を脇に。各自、担当色のジェム1個を手元に。
  4. 砂時計をひっくり返して開始。
手番 — 時計回り

手札1枚を塔のてっぺんに積む。条件は真下のカードに対して同じ色か環で隣の色か数字が同じか1違い。

  • 積めない・積みたくないときは、1枚捨てて1枚引く → 白ジェムを1個場に出す（ひび）。
  • 支柱チェック … 3段積むごとに、その3枚の数字の合計が10以上なら虹ミープルを1体、塔の脇に立てる。10未満ならひびを1個追加。
  • 補強 … 自分のジェムを使うと、条件を無視して1枚積める（各自1回のみ）。
  • 相談ルール … 手札の中身を具体的に言ってはいけない。「積める」「積めない」だけ言える。
勝敗

勝ち … 12段（＝支柱4本）を建てる。
負け … ひびが3個 ／ 砂時計が落ちる ／ 山が尽きる。

第 6 のゲーム

リフレクション・パレット

推測＆ブラフ3〜6人15分

参考にした遊び — インディアン・ポーカー、ハゲタカのえじき、ごきぶりポーカー

使うもの
カード 7色 × 0〜15
ヘクス 白 × 人数分（＝順位列）
ジェム 各自3個（ライフ）
ミープル 各自1体
セットアップ
  1. 白ヘクスを人数分、一列に並べる（左端＝1位 … 右端＝最下位）。
  2. 各自、担当色のジェム3個（ライフ）とミープル1体。
進行 — ラウンド制
  1. 各自、山から1枚引いて中身を見ずに額に掲げる（自分以外の全員に見える）。
  2. 自由に喋ってよい。嘘をついてもよい。
  3. スタートプレイヤーから時計回りに、自分のミープルを順位列のどこかに置く。すでに他人が置いた位置には置けない（早い者勝ち）。後の人ほど情報は多いが、空きは少ない。
  4. 全員置いたらカードを表にし、数字で実際の順位を確定。同じ数字なら虹の環で赤に近い色が上。
  5. 予想が当たっていた人はそのまま。外れた人はライフを1失う。
  6. スタートプレイヤーを左隣へ。
勝利条件

ライフが0になったら脱落。最後に残った1人の勝ち。

デジタル版での注意。8本のうちこのタイトルだけは会話（ブラフ）が中核なので、音声かチャットが必要になる。実装は後回しでよい。

第 7 のゲーム

セブン・ドミネーション

エリアマジョリティ2〜4人40分

参考にした遊び — エルグランデ、王と枢機卿

使うもの
カード 7色 × 0〜15 ＋ 白5枚 ＋ 黒5枚 ＋ 虹5枚
ヘクス 7色から37枚（＝領土）
ジェム 各自 担当色10個（＝支配マーカー）
ミープル 各自5体
セットアップ
  1. ヘクス37枚をランダムに選び、六角形の大きな塊に並べる＝領土。
  2. 各自、ミープル5体とジェム10個。
  3. カードをシャッフルし、各自10枚配る。
手番 — 10ラウンド・時計回り

① カードを置く … 手札1枚を任意のヘクスに置き、その上に自分のジェムを1個乗せる（＝誰のカードかを示す）。すでにカードがあるヘクスには、自分の戦力がいまの戦力より大きいときだけ重ねられる。

戦力の計算（覚えるのはここだけ）

カードの数字 ／ ＋5 ヘクスと同じ色（地の利） ／ ＋3 自分のミープルがいる（駐留）

虹＝常に地の利+5 ／ 白＝戦力15 ／ 黒＝戦力0だが、そのヘクスのカードを全部取り除く（焦土）

② ミープルを動かす（任意） … 1体を隣のヘクスへ動かす、または未配置の1体を任意のヘクスに置く。

決算 — 10ラウンド後

各ヘクスの一番上のカードの持ち主がそのヘクスを支配する。得点は、自分が支配していて、かつ隣り合っている塊ごとに（塊の大きさ）²点。

例 — 4枚つながっていれば 16点。バラバラの4枚なら 1点×4＝4点。

勝利条件

得点が一番多い人。

第 8 のゲーム

クロマティック・エンジン

デッキ構築2〜4人45分全10色を使う

参考にした遊び — ドミニオン、Star Realms、サンダーストーン

使うもの
カード 10色 × 0〜15
ジェム 10色を1個ずつ（袋に入れる）
袋 巾着袋 1枚
セットアップ
  1. 各自の初期デッキは、自分の担当色の 0〜5（6枚）。シャッフルして自分の山に。
  2. 虹カード 0〜15 の16枚を分けて、脇に勝利点の山として置く。
  3. 残りをシャッフルして山にし、8枚を表向きに並べる（＝市場）。
  4. 巾着袋に10色のジェムを1個ずつ入れる。
手番 — 時計回り
  1. 好況色 … 袋からジェムを1個引く。その色のカードは、このターンだけコスト−3。引いたジェムは袋に戻す。
  2. 5枚引く … 山が尽きたら捨て札をシャッフルして新しい山に。
  3. 購買力を数える … 手札を全部公開し、数字を合計する。
  4. 買う … コストはカードの数字。虹（勝利点）は数字＋5。購買力の範囲内なら何枚でも。
  5. 片付け … 使った手札と買ったカードをすべて捨て札に。市場を8枚に補充。

購買力の修正

同じ色を3枚以上持っていたら、その色は＋2して数える（シナジー）

白は＋5 ／ 黒は0。ただし黒1枚につき市場のカードを1枚捨てて引き直せる

終了と勝利条件

虹カードが合計5枚買われたら、そのラウンドの最後まで進めて終了。買った虹カードの数字の合計が一番大きい人の勝ち。

超越数（11〜15）の位置づけ。数字が大きい＝購買力も大きいが、コストも高い。虹15を買うには購買力20が要る。序盤には絶対に届かないので、エンジンを育てる動機になる。

作ってみて分かったこと

金型を切る前でないと得られない情報。デジタル先行の最大の利得はここにある。

共通語彙は機能した

8本すべてで 虹＝万能 ／ 白＝最大側 ／ 黒＝最小側 ／ 0＝リセット が一度も破綻しなかった。 プレイヤーは1本目を覚えた時点で、2本目の白黒虹の意味を説明されなくても推測できる。 トランプの「ジョーカーは万能」に当たる部分で、OSとして一番大事な資産になる。

超越数（11〜15）は「重いゲーム専用」だった

使ったのは 4・6・7・8 の4本で、すべて30分以上のタイトル。10〜20分の軽いゲームは 0〜9で足りた。 企画書にある「0〜10と11〜15をフチの色で仕分ける」設計は正しい。実際にその2群で分かれる。

1デッキ（160枚）で足りた

320枚＝2デッキを必要としたタイトルは1本も無い。 2デッキ同梱の根拠を「多人数対応」または「2卓同時進行」に置き直す必要がある。 あるいは価格を下げる余地として検討できる。

ダイスは「振る」ために使わなかった

2本でしか使わず、しかも用途は 数の宣言表示（ルミナス・トリック）と 色の抽選（カラー・マーケット）。 10色×各1個という構成は正しい（1人1個持てる）が、出目の深彫り彫刻の優先度は低いかもしれない。

次にやること

1. プリズム・リンクをデジタルで動かす。盤がグリッド固定なので自由配置の実装を後回しにでき、 カード・ヘクス・ミープルを一度に検証できる。
2. 次にスペクトル・ラッシュ（リアルタイム同期の検証）。
3. 数値（枚数・目標段数・得点）は、必ず実プレイで調整する。
